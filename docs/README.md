# docs/

**Po co ten folder:** Dokumentacja projektu Open Browser / OpenBridge.

**Stworzony przez:** użytkownika (pboru), struktura reorganizowana 2026-05-18.

**Zasady:**
1. Każdy podfolder ma własny `README.md` — czytaj go przed wejściem.
2. Dokumenty historyczne/superseded trafiają do `D:\projects\old-files\`.
3. Żadnych luźnych plików poza README w głównym katalogu.

**Struktura:**
| Folder | Dla kogo | Rola |
|--------|----------|------|
| `runtime/` | Model LLM wewnątrz Open Browser | Co może robić, format kopert, komendy |
| `development/` | Agenci rozwijający Open Browser | Dziennik, zasady, decyzje |
| `architecture/` | Agenci rozwijający (dawne) | Do migracji do `development/` |
| `environment/` | Agenci rozwijający (dawne) | Do migracji do `development/` |
| `handoff/` | Agenci rozwijający | Ręczne przekazanie między agentami, jednorazowe |
