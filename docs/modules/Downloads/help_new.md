## What this module does

OpenBrowser can automatically download files generated inside the ChatGPT conversation UI.

The model does not need to reconstruct ChatGPT private download APIs.
The browser/WebView download flow handles authentication and file transfer.

## Model usage

When you generate a file:

1. Create the file normally in the ChatGPT sandbox.
2. Wait for OpenBrowser to detect and download it.
3. Use HST_STATUS to check recent downloads.
4. Use PS or PY to inspect local files if needed.

## Expected status visibility

HST_STATUS should show recent downloaded files when available.

## Limitations

The Downloads module documents download behavior. It does not replace filesystem operations, file parsing, or artifact validation.
Use PS or PY for those tasks.
