# docs/handoff/

**Purpose:** One-shot context handover documents between agents. Used during a deliberate handoff, then archived to `D:\projects\old-files\`.

**Created by:** Previous agents. README added by Claude Code, 2026-05-18.

**Rules:**
1. A handoff is a one-shot document — after use, move it to `old-files/`.
2. Current project state lives in `docs/development/journal.md` and `docs/development/decisions.md` — do not create new handoffs without a specific need.
3. Naming format in `old-files`: `<description>__by-<author>__keep-until-YYYYMMDD`.
