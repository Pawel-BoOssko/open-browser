## Current execution flow

```
LLM response
  → ResponseExtractor.Finish()
  → envelope detected (first @@OPENBRIDGE_EXEC_BEGIN@@ only)
  → OpenBridgeEnvelopeParser.Parse()
  → OnEnvelopeDetected callback (MainForm)
  → OpenBridgeRuntimeApproval.TrySetPending()
  → OpenBridgeHostCommandMapper.TryMap()
  → ExecuteAndInjectResultAsync()
    → OpenBridgeRuntimeApproval.ExecutePendingAsync()
      → OpenBridgeHost.ExecuteAsync()
        → GeneralCommandExecutor.ExecuteAsync()
          → Process.Start("powershell.exe", "-NoProfile -Command \"{prompt}\"")
    → human delay (20s + truncated normal)
    → inject result into #prompt-textarea.ProseMirror
    → click Send button
  → LLM sees result
```

Every envelope gets feedback. If process produces no output → `[OpenBridge] Process exited with code N. No output.`
If cycle exceeds 120s → `[OpenBridge] Timeout: no response within 120s.`

## Envelope format (current)

```
@@OPENBRIDGE_EXEC_BEGIN@@
{
  "version": "001",
  "command": "PS",
  "payload": "Write-Output 'hello'"
}
@@OPENBRIDGE_EXEC_END@@
```

- Markers: `@@OPENBRIDGE_EXEC_BEGIN@@` / `@@OPENBRIDGE_EXEC_END@@`
- Only `PS` (PowerShell) and `HST_HELP` commands accepted
- First envelope taken, rest ignored
- `payload64` supported (base64, decoded by mapper)
- `HST_HELP` returns `docs/runtime/environment.md`, no process execution

## Architecture decisions (see `docs/development/decisions.md` for full list)

- Autonomous execution loop: LLM decides → executor executes → LLM receives result. No human in runtime.
- Host is a shared singleton, not per-command.
- Executors are hot-swappable behind `IOpenBridgeCommandExecutor`.
- Safety boundaries at OS/sandbox level, not runtime approval.
- `config/local/` is git-ignored (secrets).
