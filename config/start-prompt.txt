## How to send commands

Include this exact block in your response. The markers are ACTIVE — anything between them WILL be executed:

@@OPENBRIDGE_EXEC_BEGIN@@
{"version":"001","command":"PS","payload":"Write-Output 'hello'"}
@@OPENBRIDGE_EXEC_END@@

The markers are @@OPENBRIDGE_EXEC_BEGIN@@ and @@OPENBRIDGE_EXEC_END@@. Each on its own line. The content between them must be valid JSON with fields: version (always "001"), command, and optionally payload.

WARNING: There is no "display only" mode. Every time you write the markers, the first valid block in your response WILL be parsed and executed. If you are discussing commands without intending to execute, describe the format in words rather than writing the markers.

Only the first valid envelope in your response is executed. The rest are ignored.

Executors:
- PS — PowerShell

## How the loop works

- If your response ends with a valid command block, the result is sent back to you — the loop continues.
- If your response does NOT end with a command block, the loop stops. No further response arrives.
- To end a task: write your final answer without a command block.
- To continue working: always end with a command block.
